# Dayloom 1.2.1 Windows 任务栏图标修复

项目迁移后，Windows 开始菜单中的旧 `Electron.lnk` 仍指向已经不存在的开发目录，并与正式版共用 `app.shixu.desktop`。窗口图标和 EXE 内嵌图标均正常，但任务栏显示空白文件图标。旧开发入口已移出开始菜单并保留在本机 `release/shortcut-backup/`，任务栏实际显示已恢复为蓝色勾选图标。

## 修复

- 开发版使用 `app.shixu.desktop.dev`，正式版保持 `app.shixu.desktop`。
- 窗口显式提供任务栏图标、应用标识、重新启动命令和名称。
- Windows ICO 随程序放在 `resources/dayloom.ico`，供系统直接读取。
- 正式版启动时更新自己的开始菜单入口；使用临时数据目录的验收进程跳过此操作。
- 快捷方式脚本通过打包程序同时更新桌面和开始菜单入口，并核对目标与应用标识。
- 便携版的任务栏入口使用外层 EXE，避免引用退出后消失的解压路径。

## 验证

- 前端构建、主进程语法检查通过。
- 打包版本的 17 项桌面回归通过，包括任务编辑、日历、重启持久化、备份导入导出与损坏数据恢复。
- 使用 Windows 属性存储读取窗口的应用标识、图标资源及启动命令，确认指向当前程序。
- 重新从桌面快捷方式启动，实际检查任务栏图标已恢复。
- 修复前后用户数据文件 SHA-256 一致。
