# 游戏日程：设计与规则

## 界面

左侧新增「游戏日程」。页面沿用磨砂底色和已放大的字号，使用游戏颜色区分活动，不依赖游戏素材。

- 顶部：游戏筛选、新建活动、管理游戏。
- 今日待办：展示当前开放的材料本、日常，以及本周和本月尚可完成的活动；显示完成次数、刷新倒计时、计划时间和备注。
- 一周规划：按实际本地日期排出七天的活动，并可前后切换。
- 活动管理：查看全部规则，包括今天未开放的材料本；支持编辑、暂停、恢复、删除。
- 首次使用提供空状态和可选示例，不自动向已有用户数据添加游戏。

## 周期语义

每个游戏可独立设置时区、每日刷新时间、周刷新日和月刷新日。默认 UTC+8、04:00、周一、每月 1 日；这些是可编辑的起始值，不代表任何真实游戏的官方规则。

| 类型 | 开放范围 | 完成次数归属 |
| --- | --- | --- |
| 日常 | 每个游戏日 | 当前游戏日 |
| 材料本 | 用户勾选的周几 | 当前开放日；下一开放日重新计数 |
| 周常 | 整个游戏周 | 从周刷新到下次周刷新 |
| 月常 | 整个游戏月 | 从月刷新到下次月刷新 |

刷新前仍属于前一游戏日。例如每日 04:00 刷新，周三 02:00 属于周二。完成状态用活动、规则版本、周期起点一起标识；刷新后自然出现新周期，旧记录保留，不在后台无限创建普通任务。

周常和月常可以设置目标次数与计划完成日。每个活动还可设置计划时间、单次预计分钟数、单次体力成本和备注。每月第 29–31 日在短月按月末处理，并在界面说明。

## 日历衔接

周期活动投影到现有周/月日历和右侧日程。显示时转换为设备本地时间。点击活动可以查看对应周期和记录进度；未来周期不能提前完成。

拖动只调整这一周期的计划，不修改后续重复规则。目标时间必须仍在该周期内，材料本不能被拖到不开放的日期。调整规则可以改变后续周期；改变游戏的刷新规则或活动的重复方式时启用新的规则版本，避免旧进度误套到新周期。

## 存储与兼容

在现有版本 1 数据中添加可选 `gaming` 扩展。旧文件没有该字段时视为空，不修改普通任务。导入、导出和自动备份均包含游戏、活动、周期进度与本周期计划。

暂停活动会停止展示其日程，但保留规则与进度。删除游戏或活动需在应用内确认。所有示例均明确标注，不预设未经核实的真实游戏刷新规则。

## 验收重点

04:00 前后切换、周日到周一、跨月跨年、闰年与月末、跨时区显示、每周期次数互相独立、旧数据兼容、无效规则导入、暂停恢复、拖动范围限制，以及重启后恢复游戏进度。
