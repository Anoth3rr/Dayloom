## 核心逻辑

覆盖本地日期格式、闰年、跨月跨年、周/月边界、逾期待办筛选、最近 7 天范围、子任务和清单搜索、优先级排序、重叠事件分列、跨午夜事件接续、拖动转全天后的提醒处理、删除清单的数据迁移、损坏输入校验。

## 桌面交互

覆盖启动、本地保存、快速录入、任务编辑、子任务、完成和恢复、快捷键搜索、删除和撤销、清单创建与删除、周日历点击创建、日程拖动改期、月日历、深色主题、退出重启持久化、原生文件对话框导入导出、非法备份拒绝、有效备份替换，以及损坏主文件的自动备份恢复。文件对话框在自动测试中注入临时文件路径，实际存取使用原生 IPC 和文件系统。

通知 API 已接入；操作系统横幅是否实际展示受 Windows 通知设置影响，此次自动回归未验证系统横幅。

## 视觉检查

检查了浅色主界面、深色主界面、任务抽屉和周/月日历。根据用户反馈，任务主文字提高至 15px，导航提高至 14px，日期和辅助信息同步放大并提高对比度。修复了快速输入栏失焦引发的点击位移，以及弹窗恢复焦点引发的窗口内容滚动。

预览在窄面板中自动收起右侧日程栏；桌面默认使用 1440 × 940 的三栏窗口。
