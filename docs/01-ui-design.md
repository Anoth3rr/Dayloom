# 拾序 · UI 设计

设计顺序：先确定这份界面方案，再制定基础功能，最后实现。产品定位是轻盈、安静、适合每天常驻的 Windows 任务与日程桌面应用。

## 视觉方向

参考滴答清单的清晰信息层级、智能清单与并排日程布局，不复用其品牌、图标或资源。品牌名为「拾序」，英文标识 SHIXU，含义是把零散的小事拾起，让一天有序。

- 材质：Windows 原生 acrylic 窗口背景 + 应用内半透明面板；浏览器预览使用 CSS `backdrop-filter` 磨砂。旧版 Windows 降级为柔和的半透明底色。
- 氛围：雾白与淡蓝为主，背景有极淡的蓝、薄荷绿渐变；磨砂玻璃保持足够的不透明度，确保正文易读。
- 主色：矢车菊蓝 `#5278ed`。文字 `#26334b`，次要文字 `#8993a6`，线条 `rgba(104,124,158,.12)`。
- 清单色：工作蓝、生活绿、学习紫；优先级高红、中橙、低蓝、无灰。
- 字体：Segoe UI / Microsoft YaHei UI；主标题 31px，任务正文 15px，导航 14px，日期和说明 12–13px；数字使用等宽数字排版。根据实际预览反馈统一提高字号与次要文字对比度。
- 圆角：面板 18px、输入框 12px、菜单 12px、任务行 10px；低透明度阴影，避免厚重卡片。
- 动效：150–220ms 的淡入与位移；遵循系统减少动态效果设置。

## 关键页面与状态

1. 今天：日期标题、进度概览、快速输入、未完成分组、已完成折叠组、迷你月历与日程。
2. 收集箱 / 全部 / 清单 / 搜索：复用任务行，标题与空状态随上下文变化；搜索结果保留原清单与日期。
3. 最近 7 天：按日期分组，显示每天待办数量。
4. 日历：周视图与月视图；周视图显示全天栏和 24 小时时间网格，支持点击空白时段添加、拖动任务改期。
5. 任务详情：名称、完成状态、清单、日期、时间、时长、优先级、提醒、备注与子任务。底部提供保存与删除。
6. 设置：浅色 / 深色 / 跟随系统、磨砂强度、数据导入导出、本地存储说明、键盘快捷键。
7. 首次启动：预置少量可编辑的示例任务，日期相对实际启动日生成，设置中可以清除示例。
8. 空状态：用简洁图标、短句和创建按钮引导；错误通过明确提示展示，不静默吞掉保存失败。

## 可用性

- 任务完成不依赖颜色；图标与文字一起表示状态。
- 所有图标按钮提供标题和可访问名称；Tab 可达，焦点清晰可见。
- 弹窗限制焦点、Esc 关闭；输入框与标签关联。
- 搜索 Ctrl+K，新建 Ctrl+N，保存 Ctrl+Enter。
- 深色主题单独配置颜色，保持信息层级和磨砂质感。
- 紧凑宽度下收起日程右栏，仍可通过日历页和详情面板进行操作。
