# 拾序 · 基础功能设计

本设计在 `01-ui-design.md` 后制定，作为首版实现与验收依据。

## 任务

- 快速输入并按 Enter 创建。今天视图默认今天，清单视图默认当前清单，收集箱默认无日期。
- 点击任务打开编辑面板；编辑名称、备注、日期、开始时间、预计时长、优先级和清单。
- 支持子任务的添加、完成和删除。主任务完成与子任务状态互相独立。
- 任务可以完成、恢复、删除；删除后提供短时间撤销入口。
- 智能视图：收集箱、今天（含逾期）、最近 7 天、全部任务、已完成。
- 全局搜索匹配名称、备注、子任务和所属清单；支持日期与优先级排序。

## 清单

- 内置工作事项、日常生活、学习成长与收集箱；支持新建、重命名、换色和删除自定义清单。
- 删除清单时将其中任务移回收集箱，保留任务内容。
- 未完成计数随视图内容实时计算，已完成项可折叠。

## 日程

- 右侧迷你月历可选择任意日期，并显示当天已安排时段与全天任务。
- 独立周视图包含 00:00–24:00 时间网格和全天任务区；月视图展示完整月份及相邻日期。
- 点击空白日期/时段创建任务；拖动任务到其他日期或时段完成改期。
- 同时段事件并排显示，事件跨午夜时在次日继续展示。
- 可回到今天、切换上/下一周或月。
- 原生桌面通知：仅对主动开启提醒且设置日期、时间的任务触发。应用运行时检查，过去的示例任务不弹通知。

## 保存与备份

- 无需登录或后端。桌面端保存到 Electron `userData` 目录中的 JSON 文件，采用临时文件写入后重命名，并保留上一份有效备份。
- 浏览器预览保存到 localStorage；两者是各自独立的数据空间。
- 启动时校验数据结构；损坏文件不覆盖，优先读取备份并展示提示。
- 设置支持导出完整 JSON 备份与导入校验；导入为替换操作，必须明确确认。
- 示例任务以独立标记标识，可一键清除；修改过的示例任务会转为用户任务，不再被示例清理删除。
- 不提供云同步、第三方日历账号接入或退出应用后的定时提醒。

## 桌面与偏好

- 原生窗口拖拽、最小化、最大化、关闭；Windows acrylic 与兼容回退。
- 浅色、深色、跟随系统；调整磨砂面板强度。
- Ctrl+K 搜索，Ctrl+N 新建，Ctrl+Enter 保存编辑，Esc 关闭弹窗。
- 标题与日期使用中文本地格式；实际日期使用设备本地日期，不使用 UTC 截断生成日期。

## 数据模型

```ts
type Task = {
  id: string; title: string; listId: string; completed: boolean;
  date: string | null; time: string | null; duration: number;
  priority: 0 | 1 | 2 | 3; notes: string;
  subtasks: { id: string; title: string; completed: boolean }[];
  reminder: boolean; createdAt: string; completedAt: string | null;
  example?: boolean;
};
type TaskList = { id: string; name: string; color: string };
type AppData = {
  version: 1; tasks: Task[]; lists: TaskList[];
  settings: { theme: 'light' | 'dark' | 'system'; glass: number };
};
```

## 验收

1. Windows 桌面应用可运行，原生窗口控制正常；生产构建和打包成功。
2. 创建、编辑、完成、撤销删除、子任务、清单迁移、搜索与筛选均能操作。
3. 周/月视图和拖动改期正确处理本地日期、跨月与跨午夜事件。
4. 退出重开数据仍在；有效备份可导入，非法备份被拒绝。
5. 浅/深主题、键盘交互、空状态正常；主视图与日历经实际截图检查。
