# Dayloom 1.3：非常重要与账号同步

## 界面与任务行为

取消「重要不紧急」导航、专属分组和每日推进开关。在任务详情与快捷添加的优先级中增加「非常重要」。这类任务无论计划日期、最早时间和截止日期距离多远，只要尚未完成，每天都出现在「今天」的普通待办中并靠前排列。勾选即完成整个任务；完成当天仍可在已完成组找到，次日不再每日展示。日历继续表示实际安排，不生成重复的日程块。

旧长期任务自动变为非常重要；原始每日推进历史随备份保留，不再参与每日完成计数。调低优先级后恢复普通任务的日期筛选规则。

侧栏底部增加账号与同步入口，账号面板提供服务地址、注册/登录、当前账号、同步状态、立即同步、修改密码与退出。使用现有磨砂面板、蓝色主按钮和可读字号。任务、清单、周期规则与完成记录共享；本机访客数据与每个账号的缓存独立保存，合并本机数据由用户选择。

## 服务与存储

提供 Node.js 24 + SQLite 的自部署服务、持久化卷和 Docker Compose。账号采用用户名与密码，不依赖邮件服务。密码使用随机盐与 scrypt；服务端只保存会话令牌的摘要，桌面端使用操作系统安全存储保存登录凭据。所有同步接口从会话获取账号身份。限制请求体、登录频率和会话有效期，写入经过共享数据校验。

客户端离线可编辑，定时及重新联网后自动同步。每个账号缓存保存服务端基线、版本号和正在重试的请求。服务端通过版本比较防止旧设备覆盖新数据，并按请求 ID 去重；响应丢失后重复请求不会重复计数。冲突采用三方合并：不同字段的编辑合并，相同字段冲突保留可辨认的副本，删除优先且不让旧快照复活原任务。删除清单后任务回收集箱，游戏分组、规则和周期完成记录保持引用一致。

验证包括两个独立客户端共享任务、离线修改重连、并发编辑与删除、丢失响应重试、账号隔离、服务重启和桌面登录持久化。公网部署不在本次范围；局域网设备连接同一个服务地址即可使用。
