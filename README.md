# Dayloom · 拾序

Dayloom 是一款 Windows 桌面任务与日程应用，将待办清单、日历和周期事务放在同一个工作空间。采用亚克力半透明与磨砂界面，支持离线使用和 WebDAV 多设备同步。

## 任务与日程

- **管理待办**：收集箱、今天、最近 7 天、自定义清单和已完成视图，支持备注、子任务、搜索与优先级排序。
- **规划时间**：提供周历、月历和当天日程，支持拖动调整安排；只需填写最早开始或最晚完成，也可以指定具体时刻。
- **持续关注重要事项**：标记为「非常重要」的任务，在完成之前每天显示，即使截止日期还很远。
- **桌面提醒**：为有明确日期和时刻的任务开启提醒，应用运行期间按时通知。

## 周期事务

将每天、每周、每月或固定星期需要完成的事情设置为周期事务，每个周期独立记录完成次数。

普通事务适合学习、运动、整理等日常安排；游戏事务可单独设置服务器时区、每日刷新时刻和周／月刷新日，用于规划材料本、日常、周常与月常。支持一周规划、目标次数、暂停与恢复，以及本期时间调整。

## 界面与体验

浅色、深色和跟随系统三种主题，可调整磨砂浓度。Windows 11 支持原生亚克力背景；其他系统使用柔和背景。清单、当天任务和日程侧栏可以同时查看，也可展开完整日历。

常用快捷键：`Ctrl + N` 新建任务，`Ctrl + K` 搜索，`Ctrl + Enter` 保存编辑，`Esc` 关闭面板。

## WebDAV 同步

在「设置 → 账号与同步」中连接已有的 WebDAV 账号。多台设备使用相同地址、账号和同步目录，即可共享任务、清单、日程、周期规则和完成记录。

支持保存多个账号并切换，每个账号的本地缓存独立。离线修改会在恢复连接后同步；多端修改自动合并，发生冲突时保留副本。连接时可选择合并当前任务，账号凭据由操作系统加密保存。

## 数据与备份

本机数据保存在 `%APPDATA%\Dayloom\data.json`，账号缓存和连接配置也位于 `%APPDATA%\Dayloom`。升级时自动迁移旧版数据，保留原文件以便恢复。

应用自动保留上一份有效备份，也可在设置中导入、导出 JSON，或打开数据目录。无需账号即可完整使用本地任务与日程功能。

## 技术栈

| 层次 | 技术 |
| --- | --- |
| 桌面运行环境 | Electron |
| 界面与交互 | React、TypeScript、Lucide |
| 构建与打包 | Vite、electron-builder |
| 本地存储 | JSON 文件、原子写入与自动备份 |
| 跨设备同步 | WebDAV、离线缓存与冲突合并 |
